# Sounds

The six WAV files in this folder come from Kenney's "Interface Sounds" pack
(www.kenney.nl), licence CC0. They were converted to 16 bit mono 44.1 kHz, trimmed and
levelled with `finish.py`. The full pack lies in `packs/kenney-interface-sounds`.

| File | From the pack |
|---|---|
| clip.wav | confirmation_001.ogg |
| auto.wav | confirmation_002.ogg |
| rec_start.wav | maximize_006.ogg |
| rec_stop.wav | minimize_006.ogg |
| shot.wav | click_001.ogg |
| tick.wav | toggle_001.ogg |

A file with the same name in `%APPDATA%\Klip\sounds` replaces the built in one without a
new build.

`klip-sounds.scd`, `make.py`, `candidates.scd` and `candidates.py` are earlier attempts to
build the sounds from scratch. The owner rejected all of them. They are kept only as a
record and are not used.
